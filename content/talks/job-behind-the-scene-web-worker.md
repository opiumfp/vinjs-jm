  title: "Job Behind the Scene: Web Worker"
  description: The Web initially designed to show documents, and JavaScript
    brought interactivity into it. Modern applications are doing a lot of extra
    work and computations in addition to UI updates. With those requirements and
    single-thread for UI, making web app performant and responsive to the user
    input becomes challenging. **Web Worker** is the API that provides a
    beautiful abstraction on top of threading in browsers, and I want to show a
    real why, when, and how to use it in **Angular**.
