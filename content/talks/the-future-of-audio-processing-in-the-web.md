  title: The Future of Audio Processing in the Web
  description: WebAssembly opens a door for professional-grade audio software for
    the Web, allowing to compile plugins written in C, C++, or Faust. Faust is
    not only the tragic play by Goethe but a programming language for digital
    signal processing (DSP). During the talk, I compile Faust plugins right in
    online IDE into WebAssembly and load them as Web Audio Modules into a
    web-based guitar processing app.
